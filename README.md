# LeafLens: Plant Leaf Disease Classification

## Overview
LeafLens is a Computer Vision project designed to classify plant leaf images into supported disease categories using deep learning.

The project uses Python and a Convolutional Neural Network (CNN) to process leaf images and predict their corresponding classes.

## Objectives
- Preprocess plant leaf images.
- Train a deep learning model for image classification.
- Predict the class of a supplied leaf image.
- Evaluate model performance using classification metrics.

## Technologies
- Python
- TensorFlow/Keras
- OpenCV
- NumPy
- Matplotlib
- scikit-learn

## Project Modules
1. Image preprocessing
2. Plant leaf disease classification
3. Prediction and model evaluation

## Dataset
The project is planned to use the PlantVillage dataset.

Dataset source: https://github.com/spMohanty/PlantVillage-Dataset

## Project Status
Initial repository setup is complete. Model development, testing, and evaluation are in progress.

## Usage
Installation and execution instructions will be added after the implementation is tested.

## Limitations
Predictions depend on the dataset and trained model. Performance on real-world leaf photographs may differ from performance on controlled dataset images.
